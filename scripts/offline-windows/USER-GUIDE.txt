BNOC 오프라인 시연 사용 안내 (Windows x64)

1. 준비
- 이 패키지는 Windows 64비트 PC용입니다.
- ZIP으로 받은 경우 파일 탐색기에서 ZIP을 마우스 오른쪽 버튼으로 눌러 '모두 압축 풀기'를 선택하세요. ZIP 안에서 바로 실행하지 마세요.
- CD를 사용하는 경우 CD 드라이브를 열어 이 파일과 START-DEMO.cmd가 있는 폴더를 확인하세요. CD가 자동 실행되지 않으면 START-DEMO.cmd를 직접 여세요.

2. 시작과 시연
- START-DEMO.cmd를 두 번 클릭하세요. 첫 실행은 준비에 잠시 시간이 걸릴 수 있습니다.
- Microsoft Visual C++ 런타임이 없으면 Windows가 관리자 승인(UAC)을 요청할 수 있습니다. 승인을 받을 수 없으면 실행을 멈추고 관리자에게 요청하세요. Windows가 설치 후 재시작을 요구하면 재시작한 뒤 START-DEMO.cmd를 다시 실행하세요.
- 준비가 끝나면 브라우저에서 http://127.0.0.1:18081 이 열립니다. 화면의 로그인 안내에 따라 기능을 시연하세요.
- 준비가 끝나면 명령 창은 자동으로 닫힐 수 있고 서비스는 백그라운드에서 계속 실행됩니다. 시연을 마치면 3번 방법으로 종료하세요.

3. 종료
- 같은 폴더의 STOP-DEMO.cmd를 두 번 클릭하세요.
- 서비스만 종료되며 이 PC에 저장된 데이터는 남습니다. 다음 시연 때 START-DEMO.cmd를 다시 실행할 수 있습니다.

4. 데이터와 로그
- 데이터·첨부·로그는 CD가 아니라 이 PC의 다음 위치에 저장됩니다.
  %LOCALAPPDATA%\BNOC-Demo\data\<releaseId>
- 로그는 위 경로 아래 logs 폴더에 있습니다. 오류가 나면 화면에 표시된 안내와 로그를 담당자에게 전달하세요.
- 데이터를 보존하려면 위 폴더를 직접 삭제하지 마세요. CD나 ZIP을 바꿔 실행해도 릴리스별 데이터 폴더는 별도로 남습니다.
- PC방 등 공용 PC는 로그아웃·재부팅 뒤 사용자 파일이 지워질 수 있습니다. 중요한 시연 자료는 그 PC에만 보관하지 마세요.

문제가 계속되면 오류 화면을 기록하고, Windows 관리자 또는 배포 담당자에게 확인을 요청하세요. 승인되지 않은 보안 설정 변경이나 설치 우회는 하지 마세요.
