### 의견별 판단과 개선안

1. **선택 입력과 본인 요청자 반복.** 식별정보·문서 참조는 선택인데 설명·예시가 없다. 요구사항의 내선번호·회선번호·자산번호 설명을 화면에도 전달한다. 입력칸 아래에 “관련 장비의 자산번호나 알고 있는 내선·회선번호. 모르면 비워도 됩니다.”, “관련 공문의 제목이나 문서번호. 관련 문서가 없으면 비워도 됩니다.”처럼 지속 안내한다. 실제 번호·문서명은 예시로 만들지 않는다. 내 신청의 반복 요청자 열은 빼고 진행 요약에 공간을 쓴다. BNOC·작업반의 실제 요청자와 등록 시 본인 계정 확인은 유지한다.
2. **긴급 저장 여부.** 배정과 분류는 함께 저장되지만 성공 뒤 빈 정정 선택칸이 다시 나타난다. 배정 결과에 저장 분류·부서를 명시하고 평소에는 “현재 분류: 긴급”을 표시한다. 변경할 때만 현재값으로 시작하는 편집을 연다. 미저장은 저장값과 초안의 차이로 판단한다. 아직 저장하지 않은 기본 선택을 확정값처럼 표시하지 않는다.
3. **우리 반과 전체 상태.** 전체 완료는 모든 유효 작업이 끝나야 한다. 이 규칙은 유지하고 작업반 목록에 “우리 반 작업: 완료”, “신청 전체: 작업 중”을 분리한다. 상태 검색도 전체/우리 반의 대상을 구분한다. 자기 반 완료를 전체 완료로 처리해 다른 반의 남은 일을 숨기지 않는다.
4. **목록의 협업 진행.** 모든 관련 목록에 “담당 2개 반 · 1개 반 완료”와 부서별 상태 요약을 제공한다. 현재 유효 작업을 가진 부서를 중복 제거해 반수를 계산하고 과거 참여는 별도 표시한다. 과거만 참여한 반에는 “현재 담당 아님 / 과거 참여”를 표시한다. 반수와 공유 현황의 작업 건수는 다른 단위다. 건수 비율을 실제 작업량·시간의 완료율로 표현하지 않는다. 요청/작업 집계 단위와 상세 권한은 유지한다.
5. **반환과 배정 조정.** 반환 전 일정은 기록으로 보존하되 현재 실행 일정과 구분하고 예정 집계에서 제외한다. 완료 작업도 예정 대신 처리 기록으로 구분한다. BNOC 공통 상단에 “반환 처리 대기 N건”과 해당 목록 연결을 제공한다. 다른 반이 작업 중이면 신청 전체는 작업 중이므로 대기 신청 수로 반환을 추정하지 않는다. 배정 해제·부서 추가의 행동은 아래 신규 제안으로 분리한다.

### 유지할 업무와 설계 경계

신청 검색은 버튼·Enter, 초기화는 한 번 조회다. **BNOC 현황 빠른 필터는 즉시 적용**한다. 필터를 접는 제안은 이 동작을 통일하자는 뜻이 아니다. 기존 필수/조건부/선택 입력, 희망 일정과 작업 일정의 구별, BNOC 분류·부서 배정과 작업반 일정/담당 인원 책임, 명시적 저장·서버 커밋 뒤 성공 표시, 충돌 때 입력 보존·명시적 교체, 공유 필드/상세/수정 권한과 현재 집계 산식을 유지한다. 자동 저장·우선순위 자동 정렬·새 승인 절차·공유 상세 확대를 추가하지 않는다. 임시 단계·가짜 이름/계급·화면의 모의/대회용 설명도 추가하지 않는다.

### 중간 목표를 닫는 기준 — 제안

대표 과제는 여섯 묶음으로 제안한다: 요청 등록/조회, BNOC 분류·복수 부서 배정과 집계 구별, 작업반 일정·상태 처리, 반환 재배정/완료 후보고, 부서별 병력·야간 현황, 공지·첨부. 검수자는 실제 또는 예상 사용자다. 먼저 업무 담당자의 검수로 부대 업무와 다른 점을 확인하며 다른 역할 사용자 검수 여부도 따로 기록한다. 실명·실제 운영 자료를 공개 시연이나 증거로 넣지 않는다.

1. **막힘 없음:** 해당 역할의 대표 과제를 화면 동작 설명 없이 끝낸다. 완료 여부·도움 요청·잘못 선택한 부서/날짜/집계 단위·되돌아간 화면·시간을 기록한다. 업무 자체를 처음 배우는 시간과 UI 설명 도움을 구별한다. 여러 역할 사용자를 확보하기 전에는 한 사람 검수를 전체 사용자 적합성으로 일반화하지 않는다.
2. **같은 조건으로 비교:** 개선 전후 같은 역할·과제·자료 조건에서 측정한다. 아직 기준판의 시간이 없으므로 ‘몇 % 빨라짐’을 정하지 않는다. 전후 시간이 나아졌는지와 새 혼동이 생기지 않았는지를 함께 확인하고 반복 학습 효과도 기록한다. 측정 뒤 필요하면 수치 목표를 따로 검토한다.
3. **표현과 접근:** PC1280/1440에서 핵심 과제 수행·현재 위치·첫 오류 초점을 확인한다. 문자 대비는 일반 글자 4.5:1, 큰 글자 3:1을 적용하고 클릭 영역은 WCAG 2.2의 24×24 CSS px 또는 해당 예외 조건을 확인하는 안이다. 이 일부 항목 확인만으로 전체 WCAG 준수를 주장하지 않는다.
