- 정비: 직접/대리 신청·문서 대기·일반/긴급 배정과 사후 정정·작업반 상태/일정/담당 인원·반환 재배정·미분류 완료 후보고·검색·일/주/월 일정·이력·알림.
- 부대 운영: 전체 작업의 할당/완료/남은 건수와 공유 목록, 각 부서의 명부·휴가/출장/가용·야간 근무, 부서 상호 조회, BNOC 공지와 실제 문서 첨부. 일반 요청자의 공유 조회가 상세정보 권한을 넓히지 않는다.
- 실제 저장: 요청/작업/이력/알림/명부/공지와 파일 내용 보관, 같은 제출 중복 방지·오래된 변경 거절·현재 권한 검사. 최초 배정에 작업 일정을 넣거나 반장을 지정하지 않는다.

최종 패키지 (비공개 원본 이력: `../../runtime/evidence/backend-implementation-20261013/package-final-history.json`)는 화면을 JAR에 포함하며 내장 파일과 실제 빌드의 해시를 대조했다. 업무 규칙 격리 오류 검사 (비공개 원본 이력: `../../runtime/evidence/backend-implementation-20261013/server-sensitivity-RolEQw/summary.json`)는 정상 코드 통과 후 일정 자동 입력·미분류 배정·다른 로그인 출처·완료 확인 누락 네 오류를 각각 지정 assertion으로 잡았다. 이력 표기 정정 전 실행판이며 선택된 업무 규칙·검사는 최종판과 같다. 표시 정정에는 별도 단위·실제 화면 검사를 적용했다. 실제 실행 결과와 독립 검토·미실행을 구별한다. 실제 공군 연동·인터넷 공개 배포·유예된 이식 고도화는 이번 완료 범위에 포함하지 않는다.
